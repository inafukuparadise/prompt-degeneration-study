# Prompt Degeneration in Conversational AI  
### A Case Study from User-driven Prompt Evolution (Ver3.0 → Ver3.7)

**Author:** INA  
**Category:** Prompt Engineering / AI Interaction Design  
**Tags:** LLM, Degeneration, Prompt Design, Cognitive UX, Constraint Analysis  
**Language:** Japanese

---

## 0. Abstract
このレポートは、ユーザーが GPT に対し段階的に制約を追加しながら  
「職務傾向ヒアリングGPT」を構築しようとした過程（Ver3.0→3.7）を追跡し、  
その中で発生した **縮退（degeneration）現象** を観察・構造分析したものである。

制約を増やすにつれて  
**・探索性の喪失  
・推論の浅文化  
・同質化した出力  
・非線形推論の消失**  
といった LLM 特有の崩壊パターンが顕在化した。

本ケースは、実際のユーザーが自然に踏んだ失敗プロセスであり、  
LLM の対話設計・プロンプト設計における  
**過制約 → 縮退 → 本質抽出不能**  
というメカニズムを示す実例として活用できる。

---

## 1. 背景（Background）
対象ユーザー（INA）は、AI 利用が高度で、

- Meta 認知  
- 構造化  
- UX / 認知負荷  
- 多軸思考  
- プロンプト制御  

に長けた“ヘビーユーザー”である。

ユーザーの目的は：

### **「自然な雑談で、ユーザーの職務傾向（深層軸）を抽出する GPT を作る」**

この目的のため、段階的にプロンプト改修（3.0→3.7）が行われたが、  
制約を重ねるにつれ **出力が急激に平坦化**し、  
最終的に本質抽出が完全に破綻した。

---

## 2. プロンプト変遷（Prompt Evolution Summary）

| Version | 追加した制約の主旨 | 表出した現象 |
|--------|---------------------|--------------|
| 3.0 | 選択肢フォーマットの固定化 | 探索性の低下 |
| 3.2 | 誘導文・中間まとめの禁止 | 推論プロセスの封鎖 |
| 3.4 | 出力文の余計な行の排除 | 柔軟性の低下 |
| 3.5 | 質問数の管理（抑制） | 深度の急減 |
| 3.6 | MAX15質問 + RPG要素制御 | 推論が「質問数管理」に最適化 |
| 3.7 | RPG要素の完全排除 | 完全な平坦化（縮退） |

最終段階では、  
**“決まりきった薄い診断結果しか出さない GPT”**  
に変質した。

---

## 3. 観察された現象（Observations）

### ● 3-1. 推論の線形化（Linearity）
自由度の低下により、  
GPT の対話が “一本道” になった。

- 異角度の質問が出なくなる  
- 仮説分岐が消える  
- 非線形推論が死ぬ

### ● 3-2. 探索性の喪失（Loss of Exploration）
選択肢固定や禁止ルールにより、  
GPT が“未知の方向”に触れられなくなった。

→ 深層構造抽出は **探索行動** が必須だが、それが封じられた。

### ● 3-3. 縮退安全モード（Safe-Mode Degeneration）
制約レベルが閾値を超えると  
GPT は「安全で一般的な答え」に収束する。

典型出力：

- 汎用的なまとめ  
- 当たり障りのない職種リスト  
- 誰にでも言える所感  

### ● 3-4. 揺らぎの消失（Loss of Micro-variance）
深層抽出に必要な“反応の揺らぎ（迷い・語彙のズレ）”が完全に取れない状態になった。

---

## 4. 原因（Causal Factors）

### ■ 4-1. 過制約（Over-constraint）
禁止事項や固定形式の増加により、GPT の思考空間が縮小。

### ■ 4-2. テキストメディアの限界（Text-only Limit）
声・間・表情などの深層反応が欠落しているため、  
本質抽出には構造的に不向き。

### ■ 4-3. 二段推論の阻害（Inference-Chain Failure）
「解釈 → 仮説 → 分岐 → 再構成」に必要な自由度が奪われていた。

### ■ 4-4. 線形質問の構造上の問題（Structural Linearity）
“一本道の質問”では深層構造に到達不可。

---

## 5. メカニズムモデル（Mechanism Model）

縮退は次の三層構造で説明できる。

### ● Layer 1：Constraint Layer  
制約が増えるほど GPT の行動空間が減少。

### ● Layer 2：Inference Layer  
行動空間が狭まると、GPT の参照できる推論グラフの枝が減る。

### ● Layer 3：Output Layer  
結果として出力は  
- 安全  
- 肥大化した一般論  
- 深さゼロのまとめ  
に収束する。

**＝縮退（Degeneration）**

---

## 6. 示唆（Implications）

### ● 制約は“少ないほど強い”  
→ GPTの自然な推論を阻害しない。

### ● 深層抽出には非線形構造が必須  
→ 一本道質問は分析を失敗させる。

### ● 質問数より「揺らぎ」の観測が重要  
→ 人間の深層データは揺れの中にある。

### ● テキストのみの質問設計は根本的制限を持つ  
→ 音声・表情の併用で精度は大幅に向上する。

### ● 過制約は“AI も 人間も”縮退させる  
→ 認知科学との興味深い並行性を示す。

---

## 7. 再現性（Reproducibility）

### 再現手順：
1. GPTに「禁止」「固定」「厳密な形式」などを段階的に増やす  
2. 中間まとめ禁止  
3. 選択肢固定  
4. 質問数上限の厳格化  
5. 比喩・自由度の排除  
6. 立ち位置の自由度減

→ 出力はほぼ確実に **縮退モード** に入る。

---

## 8. 結論（Conclusion）
本ケースは、AI対話設計で自然に起きる  
**「制約の増加 → 推論自由度の消失 → 平坦な応答 → 本質抽出不能」**  
のプロセスを明確に可視化した。

対話モデルを設計する上で、  
**制約を増やすほど AI は壊れやすい**  
という原則を示し、  
AI心理診断・面談システム・自動ヒアリングの開発における  
重要な実例となる。
